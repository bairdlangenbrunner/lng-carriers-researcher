# Scripts — what each does and when to read its source

Per-script reference for `scripts/` (moved out of `CLAUDE.md` 2026-09-23 so it is read when a
script matters, not on every session start). Every script runs from the repo root as
`python scripts/<name>.py`; `paths.py` anchors `work/` to the repo root regardless of cwd.
The review app's entry points (`review_data.py`, `server.py`, `suggestions.py`, `living.py`,
`push.py`) are documented in `review_app/README.md`, not here. `review_app/` imports from
`scripts/`, never the reverse.

Trust the scripts by default. They are versioned scaffolding, not throwaway code. If you fix one,
commit the fix in the same batch with a note in that batch's `notes.md`.

**`--help`:** every script here parses `--help` **except `merge_fills.py`**, which has no argparse
and starts the live merge + gate pipeline as soon as it runs. Read its docstring instead.

## Shared plumbing

| Script | Purpose | Read source when |
|---|---|---|
| `paths.py` | shared path resolution — `work/` defaults to `<repo_root>/work/` (override `LNGCT_WORK_DIR` / `--work-dir`), batch outputs to `batches/<dir>/` via `--out` | A script writes somewhere unexpected; adding a new scratch location |
| `backend_io.py` | the one canonical backend-CSV loader — `load_backend()` returns header, data rows, colmap and `header_index`; raises `BackendNotPulled` with a "run pull_backend.py first" message; shared backend date parsing | A script mis-reads a column; a new derived accessor is needed |
| `pull_backend.py` | fresh backend pull through the `gws-gem` read-only CLI profile (`DEFAULT_SPREADSHEET_ID`, tab addressed by title) → `work/backend.csv` + `work/backend.colmap.json`, the column-index map derived from the header row. Never a public export URL | Schema changed; column indices look wrong; the gws profile or tab title changed |
| `lookups.py` | data loaders: `CONTROLLED_VOCAB` (shared by build + QC) + builder/owner facts tables | Adding a vocab value; changing the facts-table schema |
| `seed_lookups.py` | seed/refresh `data/shipbuilder_facts.csv` + `shipowner_facts.csv` from the live backend | New yard/owner to capture; re-deriving facts after backend edits |
| `normalize.py` | canonical builder/owner names + `normalize_vessel_name` (module, imported by others) | Adding a new yard or owner; clusters over- or under-merging |
| `fetch.py` | shared curl layer — `fetch_page()` (compressed, charset-aware, PDF/ZIP→text with OCR, TLS/UA retries, empty-PDF re-fetch, extra headers) + `fetch_text()` / `download()`. Clears bot walls itself: Cloudflare firewall page → `curl_cffi` Chrome TLS impersonation (`cf_impersonate`); JS challenge (Cloudflare, AWS WAF, Imperva) → real-Chrome clearance cookies (`cf_clearance`), once per host per process. CLI: `python scripts/fetch.py <url> --head 2000` (the `notes` line says which route worked). **Byte-identical copy in the terminals and pipelines repos — change it in all three** | A host needs a new fetch quirk; PDF extraction failing; a new kind of bot wall (add its cookie prefix to `cf_clearance.WALL_COOKIE_PREFIXES` and its body marker to `_WALL_MARKERS_ANY_STATUS`) |
| `cf_clearance.py` | earns / stores bot-wall cookies (`cf_clearance`, `aws-waf-token`, Imperva `incap_ses_`/`visid_incap_`/`nlbi_`) by driving Google Chrome over DevTools (no automation flags, so Turnstile passes in ~5 s; a page is "cleared" when neither its title nor its rendered DOM looks like a challenge — a real 404 counts); store `work/cf_clearance.json` (gitignored, IP-bound; ~1 yr for Cloudflare, days for AWS WAF); `LNGCT_NO_BROWSER=1` forbids the launch; CLI `python scripts/cf_clearance.py <url>` / `--show` | Chrome path changed; challenge no longer clears; need a different CDP flow |
| `sweep.py` | polite bulk fetch — **the only way to sweep many URLs on one host** (wraps `fetch_page()`). Per-host pacing with jitter (6 s ± 2 s; tracker hosts vesselfinder.com / marinetraffic.com / marinetraffic.org 10 s ± 3 s, bloomberg.com 30 s ± 10 s after its 2026-09-21 "unusual activity" flag — `--delay` can raise a floor, not lower it); per-host circuit breaker (3 consecutive `000`/429/403, or 8 consecutive 404s after 200s — stop the host for the run, record its remaining URLs as skipped, retried on re-run; a host that tripped earlier re-trips on its first failure); `--urls FILE` or `--template '…{imo}' --imos FILE|LIST`; `--max` per host per run; resumable JSONL under `work/`; exit 1 when a breaker tripped | Tuning delays / breaker thresholds; a new tracker host for `HOST_DELAYS`; a new failure status |

## Verification gate and confidence

| Script | Purpose | Read source when |
|---|---|---|
| `url_verifier.py` | the §3.8 verification gate — citable-shape check (GEM / abarrelfull / shorteners / navigation URLs banned in code), `citable_form()` / `IGU_PDF` (an IGU landing page → that edition's report PDF, gated and cited in its place by every gate caller — IG §1), HTTP status, soft-error + bot-wall detection with Wayback fallback (bot-block ≠ dead; status `000` is `blocked`, never `dead`), redirect re-check, PDF text, normalised content match, host adapters that verify SPA pages (shipvault.com — and its citable unit-record URL `shipvaultapi-…/api/units/{id}` — and marinetraffic.com) against the JSON they load; `value_variants` renders what a page actually says for a cell value (number/price/date forms, Status `active` ↔ delivery wording, `on order` ↔ order wording, hull numbers with or without the yard tag); a **Vessel type** value counts only in the article's own text next to vessel wording (`corroborates(…, field="Vessel type")`, RF §3.8c rev 29); per-host pacing on every live fetch (`HOST_MIN_GAP` 2 s, raised to the `sweep.HOST_DELAYS` floor for trackers and bloomberg.com); graded reasons via `classify()` (ok / banned / dead / blocked / uncorroborated); `--check`, `--value`, `--log` | Verifier flagging false positives or negatives; new soft-error / bot-wall pattern; new banned host |
| `igu_refs.py` | the IMO-keyed check behind every IGU report-PDF ref (IG §1): `IguTable.check(edition, imo, field, value)` reads `work/igu_fleet_<edition>.json` — True (IGU prints it for this IMO) / False (prints something else, IMO not listed, no such column, or the row has no IMO) / None (no extraction → the text gate stands). `corroborates_cell(url, value, field, imo)` = `url_verifier.corroborates` + that check; it is the gate in `build_workbook.py --mode fix`, `merge_fills.py`, `citation_qc.py --corroborate`. Hull forms (`Hull 3387 (HDHHI)` ↔ `Al Nigyan (3387)`, `Hull No.YZJ…`, ex-name hulls), builder labels through the learned pairs, Status by fleet / orderbook table | A real IGU value rejected (or a wrong one passed); a new backend column IGU prints (`FIELD_KEY`); a new hull form |
| `confidence.py` | the §5 grade (RF rev 28) — `grade(passes, field, value, caps)` turns the gate's own verdicts into G/Y/R + a `why`: a **live** pass whose match is a keyed record (IGU by IMO, shipvault / marinetraffic unit record) or a **distinctive** value is G, two independent live hosts are G, archive-only or a generic value on one host is Y, nothing surviving is R; the carve-outs (`CAP_ROLL_FORWARD` §4.18, `CAP_DERIVED` DF §5a, `CAP_CONFLICT` §3.8c, a researcher `cap_reason`) cap at Y and never raise. Called by `merge_fills.py` and `build_workbook.py --mode fix` | A value class is graded generic that shouldn't be (`GENERIC_FIELDS` / `distinctive`); the gate gains a new reason marker (`_KEYED_MARKS`, `_ARCHIVE_MARK`) |
| `citation_qc.py` | §3.8a rot sweep — grades every existing backend `[ref]` URL once (`work/citation_qc.csv`, live sheet rows); `--corroborate` runs the per-cell §3.8c gate; re-fetches every fresh `dead` verdict once; `--sheet-rows`, `--hosts`, `--delay`, `--resume`, `--regrade` | Changing the triage grades or output columns |
| `regrade_confidence.py` | retroactive §5 re-grade (RF rev 28) — re-runs the §3.8c gate live on every `hold` line of already-built batches and promotes `hold -> accept` on a G. **Promote-only**: never demotes, never rejects, skips any line a person decided (`review_log.jsonl`), skips `preserve_ref` / value-less ref lines; writes the new grade into the batch's source JSON + `decisions.csv` and appends an honest log record (`reviewer: "§5 regrade"` — read as undecided by the app, never a forged click). Dry run by default (`work/regrade_report.csv`); `--apply` writes; gate results cached in `work/regrade_gate.jsonl` | Adding a batch mode; changing what takes a line out of scope |
| `wayback_save.py` | archive URLs to the Wayback Machine — **the only way this repo archives**. Save Page Now 2, always authenticated (IA S3 key from `$IA_S3_AUTH` or the keychain item `archive-org-s3`; exits rather than going anonymous), 6/min under the 7/min cap, polls each job, retries SPN-side errors. Default = every distinct backend `[ref]` URL minus banned shapes; `--urls FILE`, `--sheet-rows`, `--within 30d`, `--retry-errors`, `--dry-run`. Resumable `work/wayback_save.jsonl` with citable `snapshot` URLs; never edits the backend | Changing SPN2 options, retry set, or rate |

## Data fill and fix batches

| Script | Purpose | Read source when |
|---|---|---|
| `derive_fills.py` | data-fill: select in-scope rows (`--since`), compute derivable autofills, list per-cluster research targets → `work/data_fill.json` + `work/research_tasks.json` | New derivable column; changing the row-selection filter |
| `derive_corroborate.py` | corroborate-batch selector (cells whose only ref is the IGU 2025 landing page) emitting the data-fill file pair. **Superseded** for IGU-sourced cells by the settled IGU sole-source rule (IG §5.4, 2026-09-21); kept for a deliberately-ordered corroboration pass only | Baird asks for a corroboration pass; changing the scope selector |
| `merge_fills.py` | data-fill: merge every `work/research_*.json` (clear stale ones first) + run the central §3.8c re-verify gate. Honours `derivable: true` only on the DF §5 autofill columns (`DERIVABLE_FIELDS`); gates a `derived_from: {total, n}` Price on the order **total** and caps it at Y (DF §5a); demotes any other fill left with no URL; sets each fill's `confidence` / `confidence_why` via `confidence.grade` (RF §5 rev 28). **No argparse — runs immediately** | Verifier behaviour changes; new research-output key; a new derivable column |
| `other_names.py` | former Names → `Other names` (RF §4.16): derives an `append_ref` `Other names` cell from every `Name` cell in a fix batch — existing cell + `"; "` + former Name, gated on the former name alone (`gate_value`; exact name, never scattered tokens; candidates = the new Name's refs + the row's existing `Name [ref]` (an IGU landing page swapped for its PDF) + the IGU PDF of every edition whose extraction prints the former name for the IMO, then the shipvault record for the IMO as a last resort), Y / blank ref when nothing passes. `--batch <dir or fix.json>` patches in place (idempotent, stamps `former_name`; run before `build_workbook.py`); `--collect <dirs> --out fix.json`; `--include <row_id>`; `--igu-ex <edition>` (RF §4.17) adds every IGU `(ex-…)` name by IMO, hulls yard-tagged `Hull NNNN (Tag)`. Skips spelling / truncation fixes (similarity ≥ 0.85 or a prefix), names claimed by another row, placeholder → placeholder | A real rename classified as a spelling fix (or the reverse) — tune `SPELLING_RATIO` / `is_placeholder`; a new multi-valued column |
| `delivery_history.py` | delivery history (RF §4.19): for every fix-batch `Delivery year` cell that moves the year **later**, adds an `append_ref` `Previous delivery year(s)` cell (former year, gated) and `Delivery delayed` = `yes`, both at the Delivery year cell's confidence. Ref candidates: the row's existing `Delivery year [ref]` URLs where the year shares a sentence with delivery wording (`states_delivery_year`) + the IGU PDF of each edition printing the former year for the IMO. `--batch <dir or fix.json>` patches in place (idempotent, stamps `former_year`); `--dry-run`, `--no-gate` | A real delivery statement rejected (or a sidebar date accepted) — tune `_DELIVERY_WORDS`; a new IGU edition's PDF URL |
| `igu_hulls.py` | RF §4.17: IGU `Name (hull)` entries → a fix batch — by IMO, fill a blank `Hull number` (`Hull NNNN (Tag)`, IGU PDF ref) or restyle an untagged one with its yard tag (`preserve_ref`); by hull + builder family, name a row still carrying its hull placeholder (+ IMO). Yard conflicts, different hulls and anything an un-applied batch already proposes are flagged, not proposed. `--edition`, `--out <batch>/fix.json`; then `other_names.py --batch` | IGU prints a new hull form; a false yard match; a new yard needing a tag (`FALLBACK_YARD_TAGS` in `other_names.py`) |
| `build_workbook.py` | xlsx scaffolding — sheets, colour fills, frozen panes, headers (modes: ref_fill / discovery / data_fill / fix / fsru / igu). `discovery` mode refuses a candidate with a filled data cell and a blank `[ref]` (only `unknown` and a placeholder Name stand without one). `fix` mode rebuilds corrected full rows from a `fix.json` (optionally `--base <corrected_rows.csv>`), runs every ref through the §3.8c gate (`igu_refs.corroborates_cell`), computes the §5 grade, and writes the **gated** `fix.json` (surviving refs, `dropped_refs`, `confidence`) into `--out` — that copy, not the source, is what `apply_batch.py` reads; `preserve_ref:true` rewrites the value and keeps the paired `[ref]`; `append_ref:true` + `gate_value` gates an added element and appends passing refs to the existing `[ref]` (RF §4.16); warns when a Name change has had no former-name check. `fsru` / `igu` modes render the reconciliation JSON into the 10- / 11-sheet comparison workbooks (no `[ref]` cells proposed) | Adding a new sheet section; changing colour convention; changing fix-mode gating; changing the fsru or igu sheet set |
| `recalc.py` | open the xlsx, force recalc, return any formula errors. Zero errors required before committing | Always run before committing the batch |
